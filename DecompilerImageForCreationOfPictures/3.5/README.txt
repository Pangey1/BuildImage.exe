# DecompilerImageForCreationOfPictures (v3.5)

Support for video decompilation has been added!
You will need `ffmpeg.exe` to split video into frames and extract audio into `.wav`.

## Download FFmpeg
Download link for FFmpeg: https://disk.yandex.ru/d/O8CSv2tNEe9Buw

## Usage
* Drag and drop any image (`.png`, `.jpg`, `.bmp`, etc.) or video (`.mp4`, `.avi`, `.mkv`, etc.) onto `DecompilerImageForCreationOfPictures.exe`.
* Or run via command line with a custom FFmpeg path:
```cmd
DecompilerImageForCreationOfPictures.exe video.mp4 -f ffmpeg.exe
```
